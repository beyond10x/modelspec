# Status

0.7.1 is the latest release; each release carries a prebuilt binary for Linux x86_64
([changelog](https://github.com/beyond10x/modelspec/blob/main/CHANGELOG.md)). 0.1.0 was
milestone M0, the semantic core. `modelspec train --backend vulkan` trains on one Vulkan device
within the GPU tolerance of the CPU reference since 0.4.0, and since 0.6.0 it writes and resumes
checkpoints there, `modelspec infer --backend vulkan` runs a checkpoint on the device, `modelspec
compile` writes a sealed artifact directory and `train --record` with `observe` records and
replays a run. A binary built without the `vulkan` feature refuses that backend with
`E-TARGET-001`.

Since 0.7.0: `train --backend vulkan` refuses a diverged run with the CPU run's `E-TRAIN-001`;
the plan verifier is bounded on an untrusted artifact; a matmul kernel's module id covers its
tile; `--ui ui/dist` serves the observatory UI, which draws the loss and every metric per step;
and a run's events carry parameter and gradient statistics on sampled steps
(`--statistics-every`). The rows below that start with "Since 0.7.0" are these.
Since 0.7.1: every dispatch of a plan has a FLOP and a byte count that `ir --stage kernel` and
`train --backend vulkan --profile` print, and the Vulkan descriptor pool counts every view a
dispatch reads and writes.
M1, native Vulkan execution, is in progress ([Roadmap](./roadmap.md)).

| milestone | state |
|---|---|
| M0 semantic core | done: released as 0.1.0 |
| M1 native Vulkan execution | in progress: Vulkan training since 0.4.0; `compile`, Vulkan checkpoints and Vulkan `infer` since 0.6.0; the observatory UI and Vulkan non-finite loss refusal since 0.7.0; per-dispatch FLOP and byte counts in `--profile` since 0.7.1 |
| M2 to M4 | designed in DESIGN.md § 1; not built |

## Every capability

**Shipped** means a test or task in the repository holds it, the row names that test or task, and
`task ci` runs it on every change; a test that needs a Vulkan device is built by `task ci` and run
with `--ignored` on a machine that has one. **Planned** means it is in the M1 epic, `epic:m1-vulkan-execution`, and not built. The table
is generated by `modelspec-docs` from its list of capabilities, and `task docs-check` fails when the
test a row names no longer exists.
