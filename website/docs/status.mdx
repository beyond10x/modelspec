# Status

0.1.0 is the latest release and the first. It is milestone M0, the semantic core: `modelspec
check`, `modelspec ir --stage tensor|training` and `modelspec train --backend cpu` on the M0
subset of the language, with a prebuilt binary for Linux x86_64
([changelog](https://github.com/beyond10x/modelspec/blob/main/CHANGELOG.md)).

On `main`, not in a release yet, `modelspec train --backend vulkan` trains on one Vulkan device
within the GPU tolerance of the CPU reference. A binary built without the `vulkan` feature refuses
that backend with `E-TARGET-001`. M1, native Vulkan execution, is in progress
([Roadmap](./roadmap.md)).

| milestone | state |
|---|---|
| M0 semantic core | done: released as 0.1.0 |
| M1 native Vulkan execution | in progress: Vulkan training on `main`; `compile` and Vulkan `infer` not built |
| M2 to M4 | designed in DESIGN.md § 1; not built |

## Every capability

**Shipped** means a test or task in the repository holds it, the row names that test or task, and
`task ci` runs it on every change; a test that needs a Vulkan device is built by `task ci` and run
with `--ignored` on a machine that has one. **Planned** means it is in the M1 epic, `epic:m1-vulkan-execution`, and not built. The table
is generated by `modelspec-docs` from its list of capabilities, and `task docs-check` fails when the
test a row names no longer exists.
