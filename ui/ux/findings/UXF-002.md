## What the screen shows

Before the first event the header holds the title and the state `connecting`; `RunStarted` sets
the run id, and `App.vue` inserts the `run <id>` line below the state, which moves the charts
section down by one line. The shift is 0.00344 at 1366x768 and 0.00418 at 1280x720, small, and
the same in both themes. A short replay makes the per-minute value large (accuracy 0.13157 over
23 events).

## Cost estimate

S: reserve the run id line's height before the id is known.
