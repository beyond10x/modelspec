## What the screen shows

In each parameter panel the value norm chart spans steps 0 to 200 (0 to 500 for
`linear-regression`) and the gradient norm chart directly below spans 0 to 100 (0 to 400), because
the last sample carries no gradient. Both charts are the same width, so the same x position is step
100 in one and step 50 in the other.

## Why it costs

A reader comparing the two norms by position, which the stacking invites, reads the wrong step; the
captions are right, the geometry is not.

## Cost estimate

S: give every chart of a run the loss chart's step range.
