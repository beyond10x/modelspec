## What the screen shows

`<header>` sits inside `<main>`, so the page has no banner landmark, and the state word with the
progress is a `<p>` with no role. The screen-only user finds the end state only as the text of
some paragraph. A failed run is announced (`role="alert"`); a finished one is not, which is an
inference from the tree, not observed with a screen reader.

## Cost estimate

S: `role="status"` on the state line, and the header outside `main` or a named region.
