## What the screen shows

Before the first step the loss panel is an empty box with only its title. With one point, the
caption shows the value but the plot draws nothing, and the step axis reads `-1` and `1`, steps
that do not exist. Parameter norms are sampled every 100 steps, so in `two-layer-relu` all four
norm charts stay blank from step 0 to step 99, half the run; in `linear-regression` for 100 of 500
steps.

## Why it costs

A blank chart with axes reads as broken or still loading; the user has to find the caption to learn
there is a value, and the axis tells them a wrong step range.

## Cost estimate

S: draw a dot for a single point and a short sentence ("no step yet") for none.
