### Landing recipe (what the scripts do)

- `.engineering/paused/2026-10-26/scripts/commit-tree.sh <tree> <msgfile>`: `git add -A`, refuses unformatted Rust, staged
  `target/` or drafts, or a home-directory path in the diff, then commits as the bot.
- `.engineering/paused/2026-10-26/scripts/push-branch.sh <tree>`: pushes the current branch as the bot (`${H}:refs/heads/<b>`).
- `.engineering/paused/2026-10-26/scripts/mkpr.sh <tree> <body.md> "<title>" <head-branch>`: scans the body with
  `b10x-gates scan-text`, opens the PR through `b10x-gates api`. `gh` is read-only here.
- `.engineering/paused/2026-10-26/scripts/wait-runs.sh <full sha>`: polls the commit's workflow runs until none is queued.
- Fast-forward: `b10x-gates bot --repository beyond10x/modelspec -- push origin "${H}:refs/heads/main"`.
- `.engineering/paused/2026-10-26/scripts/tag.sh <release-tree> <version>`: fast-forwards `main` to the release branch, tags
  and pushes as the bot. The release is done when `verify-release.sh modelspec <version>` exits 0.
- `.engineering/paused/2026-10-26/scripts/heartbeats.sh <tree-id>:<session> …`: lease heartbeats every 15 minutes while a unit
  runs. A tree ends with `worktree hook session-end`, `worktree finish --discard-cache --archive
  <tree>`, `worktree gc --repo <primary> --apply --id <id>`.
- A unit's wave-page row gets its tail (what landed, the adversary summary, the `task ci`
  counts) before the plan commit; the story's evidence is `review_outcome` (`--review
  review-result:<id> --outcome fixed`) and `test_result` (`--source "task ci" --ref <sha>`).
- Every unit's and release's commit message, PR body and post name no planning record on a
  public page and no home-directory path; `b10x-gates scan-text` checks the PR body.
