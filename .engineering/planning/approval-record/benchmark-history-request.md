# The operator asked for a benchmark history

The operator, 2026-10-23, in the coordinating session: "please start documentating the benchmark
results (I want to see a yaml file holding all the runs, and then we want to see how we evolve over
time against the opponents".

## Decisions taken by the coordinating agent

- D1: story:benchmark-history is implemented on its own branch after the benchmark wave's pull
  request and release 0.7.1, so the release does not wait for it.
- D2: the run record is an ESS entity in a new domain `modelspec.benchmark`, so the YAML file is
  validated against the generated JSON Schema like every other contract here.
- D3: the history page is generated by Rust in `crates/modelspec-docs` and drift-checked by
  `task docs-check`; no Python and no hand-drawn chart.
